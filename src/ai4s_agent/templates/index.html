远端还没有 molly-worker？查看安装 / 实现要求

当前仓库已提供固定的 molly-worker 入口。请从与控制端相同的已审查提交构建 wheel，并安装到远端专用虚拟环境；同时确保非交互 SSH 会话能从 PATH 找到它。

  1. 安装后运行 molly-worker probe --json；成功时 stdout 只包含带有 hostname、capabilities 和 details 的 JSON 对象。
  2. 模型任务使用固定的 stage、stage-input、verify-inputs、execute、status、cancel 和 fetch-output 协议；UI 不会拼接任意远端命令。
  3. 部署后先运行 ssh <SSH 别名> -- molly-worker probe --json，确认可免交互执行，再在这里保存并测试连接。

完整安全边界与请求/响应约定见 remote worker setup 和 Stage 6B protocol。

高级安全选项（远程模型任务需要）

known_hosts 是本机 OpenSSH 保存远端主机公钥指纹的信任文件，用来防止连接被冒充；它不是私钥、密码或 API Key。文献解析可使用 SSH 默认配置；选择 REINVENT4 或 Uni-Mol 时必须填写专用文件的本机绝对路径，以便执行前固定并核验远端身份。

运行环境路径（REINVENT4 / Uni-Mol）

连接 profile 只描述机器；这里把逻辑环境 ID 绑定到远端仓库和 Python。路径保存在当前用户的 environments.json，不会写入仓库。
